# 🇲🇬 Mada EcoTravel

Application mobile Flutter pour découvrir les sites écotouristiques à Madagascar.

---

## 🚀 Comment lancer le projet sur ton PC

### 1. Télécharger et extraire le projet
1. Télécharge le fichier **`mada_eco_travel.zip`** présent ici sur GitHub.
2. Fais un **clic droit** sur le fichier télécharge > **Extraire tout**.

---

### 2. Ouvrir le projet
1. Ouvre **Visual Studio Code**.
2. Va dans **Fichier > Ouvrir le dossier** (File > Open Folder).
3. Sélectionne le dossier extrait `mada_eco_travel`.

---

### 3. Installer les dépendances
Ouvre le terminal dans VS Code (**Terminal > Nouveau terminal**) et tape :

```bash
flutter pub get
